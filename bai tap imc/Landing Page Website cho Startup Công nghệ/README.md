## Mô tả dự án
Website landing page hiện đại dành cho startup công nghệ với đầy đủ các tính năng và hiệu ứng nâng cao.

### Tính năng chính:
1. **4 trang đầy đủ:**
   - Trang chủ (Home)
   - Tính năng (Features)
   - Bảng giá (Pricing)
   - Liên hệ (Contact)

2. **Giao diện responsive:**
   - Tối ưu cho desktop, tablet, mobile
   - Sticky header với navigation
   - Mobile menu với animation

3. **Animation nâng cao:**
   - Hero animation nhiều lớp
   - Feature card hover 3D effect
   - Scroll animation với AOS
   - Parallax background

4. **UI Components:**
   - Testimonial slider (Swiper.js)
   - Pricing tabs
   - FAQ accordion
   - Video modal
   - Form với floating labels

5. **Tương tác người dùng:**
   - Form validation realtime
   - Toast notification
   - LocalStorage lưu dữ liệu
   - Loading animation

## Công nghệ sử dụng
- **Frontend:**
  - HTML5, CSS3 (Grid + Flexbox)
  - JavaScript ES6+
  - GSAP (GreenSock Animation Platform)
  - AOS (Animate On Scroll)
  - Swiper.js (Slider)

- **Libraries:**
  - Font Awesome 6.4.0 (Icons)
  - Google Fonts
